# Artwork

Cut from the supplied art sheets (characters, trains/utilities, station background).

- `chars/<id>_hero.jpg` full-body panel shown in menu / character screen · `_face.jpg` avatar · `_sheet.jpg` turnaround + run/jump/slide poses
- `sprites/*.png` transparent cut-outs: obstacles, coin, magnet, sneaker, spray can, street props
- `trains/front0-4.png` train faces (yellow, blue, red, purple, green)
- `backdrop.jpg` far end-of-track scenery · `mural.jpg` graffiti wall · `billboard.jpg` / `metrosign.jpg` signs · `station.jpg` full background used behind the menus

Replace a file with another of the same name and aspect ratio to restyle it.
